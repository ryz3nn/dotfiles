***Hands-on Rust: Effective Learning through 2D Game Development and Play*** is a programming book written by **Herbert Wolverson** and published by **The Pragmatic Bookshelf**[1][2]. 

### Overview
The book is designed to teach the Rust programming language through a practical, project-based approach rather than traditional abstract syntax tutorials[1][2]. By focusing on game development, it introduces core language concepts—such as ownership, borrowing, lifetimes, structs, enums, and pattern matching—while building playable 2D games from scratch[1][2].

### Key Projects Covered
1. **Flappy Lizard (A Flappy Bird Clone):** Used early in the book to help readers get comfortable with basic syntax, control flow, functions, and setting up a development environment[2].
2. **Dungeon Crawler:** A full rogue-like game built over the majority of the book. This project introduces more advanced topics like:
   * Random procedural dungeon generation[2]
   * Managing game state and entities
   * Implementing component-based architectures 
   * Handling user input and rendering with `bracket-lib` (a minimalist ASCII/console game engine created by the author)[3]
   * Managing concurrency and performance optimization[2]

### What You Learn
* **Core Rust Philosophy:** Understanding memory safety[2] without a garbage collector through Rust's unique ownership model.
* **Idiomatic Code:** How to structure medium-sized Rust applications cleanly.
* **Minimalist Game Design:** Creating engaging mechanics using constraints (such as ASCII graphics) before getting bogged down in complex asset pipelines[3].

***

*(Note: Herbert Wolverson also authored a follow-up book with The Pragmatic Bookshelf titled **Advanced Hands-on Rust: Level Up Your Coding Skills**, which targets higher-level concepts like macros, traits, asynchronous programming, and working with the Bevy game engine[4].)*
