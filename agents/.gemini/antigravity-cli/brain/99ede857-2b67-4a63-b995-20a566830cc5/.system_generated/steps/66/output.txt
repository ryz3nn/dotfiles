The primary GitHub repository for integrating **Renet** (a client/server networking library for Rust[1]) with the **Bevy** game engine is:

👉 **[GitHub - lucaspoffo/renet](https://github.com/lucaspoffo/renet)**[1]

### Key crates inside the repository:
* **`renet`**: The core transport-agnostic client/server networking library[1].
* **`bevy_renet`**: A thin layer providing Bevy plugins, systems, and resources (`RenetClient`, `RenetServer`, etc.) to easily hook Renet into Bevy's ECS loop[2][3].
* **`renetcode`**: The secure client/server connection and authentication protocol layer[4].
* **`demo_bevy`**: A full working example/demo showcasing how to structure a multiplayer game using Bevy and Renet[5].
